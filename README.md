# Pengudoku (v1.0.8)

Welcome to **Pengudoku**, the exciting logic puzzle game where you can challenge your mind, complete daily hunts, and earn multiple rewards! This repository serves as the central hub for the game application, featuring full level guides, tutorials, and free access to active hunts.

## 🚀 Key Features

* **All-Level Tutorials:** Step-by-step guides and solutions to help you master every single level.
* **Earn Multiple Rewards:** Active gameplay unlocks in-game bonuses and exclusive player rewards.
* **Free Hunt Access:** Get all current and upcoming hunts completely free without any hidden gates.
* **Latest Build:** Fully updated to application version **1.0.8**.

## 🛠️ How to Get Started

1. **Download/Clone the Repo:** Clone this repository to access the local game guides and tutorial scripts.
2. **Review the Level Guides:** Navigate to the `/tutorials` folder to find solutions for the trickier grid levels.
